# وِرد | Wird — الإصدار 1.0.0

**وِرد** تطبيق ويب عربي خفيف للذكر اليومي، يعمل من المتصفح ويمكن تثبيته كتطبيق PWA.

## المزايا

- مكتبة أذكار الصباح والمساء والنوم وبعد الصلاة والاستيقاظ وأذكار يومية متنوعة.
- مصادر ظاهرة مع كل ذكر قدر ما توفرت الإحالة؛ التطبيق أداة تنظيم ولا يغني عن الرجوع للمصدر عند الاختلاف في اللفظ أو الحكم.
- مسبحة رقمية قابلة للتخصيص، أهداف للجولة، التراجع عن الضغطة واهتزاز اختياري.
- تقدم يومي، إحصاءات أسبوعية، سجل نشاط ومفضلة وبحث.
- حفظ محلي، مع تصدير واستعادة نسخة احتياطية بصيغة JSON.
- مشغّل لتسجيلات خارجية، وخيار تشغيل ملف صوتي من الجهاز.
- وضع داكن، واجهة عربية RTL، وتخزين غلاف التطبيق للعمل دون اتصال بعد زيارة أولى.
- قسم الصوتيات يعتمد على تسجيلات بشرية وملفات محلية فقط؛ لا يوجد تحويل آلي للنص إلى كلام في الإصدار 1.0.0.
- لا يحتاج إلى إطار عمل أو مكتبات JavaScript خارجية.

## التشغيل المباشر

يتضمن المستودع `wird.html` كنسخة HTML منفردة للتشغيل السريع. افتح `index.html` عبر خادم محلي أو استضافة HTTPS لتجربة مزايا PWA؛ أما فتح الملف المنفرد مباشرة فيدعم الواجهة والعدادات قدر ما يسمح المتصفح، لكنه لا يفعّل التثبيت أو Service Worker بصورة موثوقة. التسجيلات الخارجية تحتاج إلى الإنترنت.

## التجربة المحلية كـ PWA

تحتاج PWA إلى سياق آمن مثل HTTPS أو `localhost`. من داخل مجلد المشروع، شغّل:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000/`. على الهاتف يمكنك استخدام استضافة HTTPS بعد رفع ملفات المشروع.

## النشر على GitHub Pages

1. أنشئ مستودعًا عامًا باسم `wird-dhikr` على GitHub.
2. ارفع **محتويات مجلد `wird-release-1.0.0`** إلى جذر الفرع `main`، بما في ذلك مجلد `.github`.
3. افتح **Settings → Pages** واختر `GitHub Actions` مصدرًا للنشر عند الحاجة.
4. افتح تبويب **Actions** وانتظر انتهاء `Deploy to GitHub Pages`.
5. رابط الموقع سيظهر في سجل النشر وصفحة **Settings → Pages**. قد يستغرق النشر بضع دقائق.

يستعمل المشروع Workflow جاهزًا للنشر من GitHub Actions. راجع [وثائق GitHub Pages الرسمية](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) عند تغيّر واجهة GitHub.

## الصوتيات والحقوق

التسجيلات المشار إليها في التطبيق تُحمّل من صفحاتها الأصلية على IslamHouse، ولا تُضمّن داخل المستودع أو تُخزّن تلقائيًا. يتطلب بثها اتصالًا بالإنترنت، وقد تختلف إتاحتها تبعًا للخادم أو الشبكة. حقوق التسجيلات وشروط إعادة استخدامها تعود إلى أصحابها ومصدرها، ولا يشملها ترخيص MIT لكود التطبيق.

## الخصوصية والتخزين

تُخزن المفضلة والعدادات والسجل على الجهاز عبر `localStorage`. لا يرسل التطبيق هذه البيانات إلى خادم. احتفظ بنسخة JSON عند الانتقال إلى جهاز آخر أو قبل مسح بيانات المتصفح.

## الإصدار والاختبارات

راجع [`CHANGELOG.md`](CHANGELOG.md) و[`TEST-REPORT.md`](TEST-REPORT.md). تم فحص صياغة JavaScript وبنية HTML والروابط المحلية، وتشغيل اختبارات واجهة آلية على المقاسات والميزات الأساسية. لم يُختبر بث ملفات MP3 فعليًا على كل الأجهزة، لأنها مصادر خارجية.
